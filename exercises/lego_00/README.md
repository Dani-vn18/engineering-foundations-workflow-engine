## Rules

- Do not add external dependencies.
- Do not add classes unless you can explain what problem the class solves.
- Do not catch exceptions just to immediately re-raise them.
- Do not add retries.
- Do not persist state.
- Do not modify the tests to make the exercise pass.

## Before coding

1. What is the simplest data structure for a sequence of tasks?
2. What operation expresses "execute this task" in Python?
3. Where will you accumulate successful results?
4. What naturally happens in Python when a called function raises an exception?
